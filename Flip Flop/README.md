1) Simulation and test bench for D flip flop without reset option.
When clock is high the D input is passed to Q output.
If the clock is low the output retains its previous value.
2) The code and the test bench code for D flip flop with a reset.
   The code works as a D flip flop with input - d,clk, a reset and output -q, Q(which is q bar)
   the reset option when given will reset the flipflop ie. q=0 and q_bar=1.
