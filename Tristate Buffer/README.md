Tri-State Buffer (SystemVerilog)

Overview

This project implements a single-bit Tri-State Buffer in Verilog using continuous assignment. The output is controlled by an enable signal. When enabled, the output follows the input. When disabled, the output enters the high-impedance (Z) state.

Features

- Single-bit tri-state buffer

- Enable-controlled output

- High-impedance (Z) output when disabled

- Simple combinational logic

- Testbench for functional verification
